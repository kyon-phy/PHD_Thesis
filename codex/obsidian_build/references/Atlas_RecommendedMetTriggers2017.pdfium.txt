Further to this, please see JetTriggersToUseIn2017 coupled with the
1.7 and 1.5e34 menus from L34TriggerMenu2017 for the jet trigger
group’s recommendations and the available options.
• 
Before run 332655 (the deployment of release 21.1.10) jet GSC
triggers were off for a few lumi blocks just after the start of the
run while the beamspot determination was under way. A special GRL is
provided for analysers using these triggers, removing 262 of the
88487 lumi blocks, corresponding to 73 pb -1 out of the total 40404.4
pb -1 in the
data17_13TeV.periodAllYear_DetStatus-v97-pro21-13_Unknown_PHYS_StandardGRL_All_Good_25ns.xm
GRL
• 
Analyses using MET triggers should also check events that fire
HLT_noalg_L1J400 to see if any of these events were not fired by the
met trigger in the analysis phase-space.
