This twiki provides a short information on trigger chains recommended for physics analysis (non exhaustive
list) which were un-prescaled through a major part of the data taking. More accurate information on pre-scales
and parameters can be extracted from the trigger DB using the web browsers described below.
Please take note that pre-scales can change during various data taking periods. If a trigger chain was
pre-scaled for a short period of time it still enters the table below. If lower thresholds are important for you,
you can still use them, even if they are pre-scaled. Sometimes this would give you a better acceptance than
using higher Pt un-prescaled triggers. Email hn-atlas-trigger-menus@cern.NOSPAMch or
atlas-trigger-menu-expert@cern.NOSPAMch if you need help.
Getting information from the trigger DB
TrigConf portal (Run 2)
https://atlas-trigconf.cern.ch/  - linked also from Run Query for Run 1, 2 runs - use "show all" or "show
trigkeys" in run query and follow the links in the "Prescale keys" column ( example "find r
data18_13TeV.periodD / show trigkeys") for individual keys or for the prescale evolution.
TriggerToolWeb (Run 3)
https://atlas-triggertool.web.cern.ch  - linked also from Run Query for Run 3 runs - use "show all" or "show
trigkeys" in run query and follow links in the "Prescale keys" column (disregard links for "prescale evolution"
which incorrectly directs to a Run 2 page) ( example "find r data22_13p6TeV.periodF / show trigkeys")
RunQuery
The Run Query (http://atlas-runquery.cern.ch) is useful for getting the Super Master Key (SMK) as well as
prescale keys and bunchgroup keys for a run with links to the TrigConf portal (Run 2) or TriggerToolWeb
(Run 3), which contain further details (see above).
One can also:
For Run 2, obtain link to run's prescale evolution in TrigConf Portal by querying a run/data period
with "show all" or "show trigkeys" and clicking on "prescale evolution..." in "Prescale keys" column (
example "find r data18_13TeV.periodD / show trigkeys").
• 
For Run 2 and 3, obtain a prescale evolution graph of L1/HLT triggers, presented as (x - - 2 x
2 - - - - - - - - - - - - - - x) where x means disabled, - means no change, and
numbers are the prescales for that prescale set ( example "find r data22_13p6TeV.periodF / show tr
HLT_j420*" ).
For L1 triggers, querying "trigrates " will also display a trigger rate graph ( example "find r
data22_13p6TeV.periodF / show tr L1_J100 and trigrates L1_J100").

(see the "Trigger" tab in the Run Query site for more features).

COMA
The COMA Project (Conditions/Configuration Metadata for ATLAS) is described in TWiki
ConditionsMetadata. Its web-based interfaces can be found via the COMA Portal. COMA is useful for
quickly interrogating runs or periods, eg. for identifying the runs in each specific data period or sub-period,
and interesting associated information. It also provides trigger and prescale related information by run or
across many runs; useful to find which triggers went to which streams, which triggers were configured and/or
active during runs or periods, and what were the prescales (or prescale ranges) during those runs. You will
need the grid certificate uploaded to your browser to use the interface (see the TWiki page for help).
The COMA Period Menu shows all ATLAS Data Periods. It offers links to reports describing each
Period, its run/date range and other interesting information as well as links to other reports (AMI, Run
Query, and COMA Reports).
• 
The COMA Report Menu (link from the COMA Portal page) allows user specification of a variety of
input variables to generate COMA Reports: the COMA Report Type is determined by which input
criteria is entered by the user (inputs include: Project, Period, Run, Stream Name, Trigger HLT Chain
or L1 Item Name etc).
