    FastFrames

    FastFrames is a histogramming and ntuple reprocessing framework built around ROOT's RDataFrame. FastFrames handles the bookkeeping for you: sample definitions, luminosity and cross-section weighting, systematic variations, booking histograms, creating unfolding inputs, and much more! It is easily extendable via custom classes so users can leverage RDataFrame to define new variables.

    Just getting started? Check out the tutorial and have a look at our recommendations for how to get the most out of FastFrames.

    Quick Start

    To build from scratch, download the source and build with CMake:

    git clone ssh://git@gitlab.cern.ch:7999/atlas-amglab/fastframes.git
cmake -S fastframes/ -B build -DCMAKE_INSTALL_PREFIX=./install
cmake --build build -j 4
cmake --install build
source build/setup.sh

    Given a set of input ROOT files in /path/to/root/files, produce your metadata files with

    python3 produce_metadata_files.py \
  --root-files-folder /path/to/root/files \
  --output-path ./metadata/

    Create a basic FastFrames configuration config.yml:

    # config.yml
general:
  input_filelist_path: metadata/filelist.txt
  input_sumweights_path: metadata/sum_of_weights.txt
  output_path_histograms: output
  xsection_files:
    - files: ["/path/to/xsection/files.txt"]
      campaigns: ["mc20a", "mc20d", "mc20e"]
  luminosity:
    mc20a: 36646.74
    mc20d: 44630.6
    mc20e: 58791.6
  default_event_weights: "weight_mc_NOSYS *
                          weight_beamspot *
                          weight_pileup_NOSYS *
                          globalTriggerEffSF_NOSYS *
                          weight_leptonSF_tight_NOSYS *
                          weight_jvt_effSF_NOSYS"
  default_reco_tree_name: reco
  default_sumweights: NOSYS
  use_rvec: true
  automatic_systematics: true

samples:
  - name: ttbar
    dsids: [410470]
    campaigns: ["mc20e"]
    simulation_type: fullsim

regions:
  - name: electron
    selection: el_pt_NOSYS.size() > 0
    variables:
      - name: met_met
        definition: met_met_NOSYS / 1000.
        binning:
          min: 0
          max: 500
          number_of_bins: 20
      - name: el_pt
        definition: el_pt_NOSYS / 1000.
        binning:
          min: 0
          max: 500
          number_of_bins: 20

    and produce some histograms!

    python3 FastFrames.py --config config.yml
