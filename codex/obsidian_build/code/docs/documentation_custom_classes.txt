Custom Classes
For most analyses the default CPAlgs outputs are too simple to be useful.
FastFrames provides an easy way to define new variables that can then be used
to fill histograms: custom classes. Essentially this is C++ code that you
compile which FastFrames then loads and runs!
Creating a Custom Class
We provide a template class at
FastFramesCustomClassTemplate
that should be used as the base of any custom classes. Choose a name, e.g.

FastFrames Environment Setup
You should have FastFrames installed and your environment already set up!
The FastFrames setup script lets your custom class find FastFrames
automatically. If not, this step will fail as it will not find FastFrames.
This will create another
setup.sh
script in your chosen build directory. Make
sure to
source
setup.sh
for the custom class before trying to use it, otherwise FastFrames will not be
able to find it!
Defining Variables
The custom class has four main functions within which you can define variables:
defineVariables()
: called when processing histograms for the reco tree
defineVariablesNtuple()
: called when producing ntuples for the reco tree
defineVariablesTruth()
: called when processing histograms for the truth tree
defineVariablesNtupleTruth()
: called when producing ntuples for the truth tree
FastFrames also provides a few helper functions to make life easier. They are
documented at
Helper Functions
.
Using a Custom Class
You can specify the name of the custom class to run in the
general
block of
your configuration file:
general
:
custom_frame_name
:
ExampleFrame
FastFrames will automatically find your compiled class, provided you sourced
your custom class's setup script!
