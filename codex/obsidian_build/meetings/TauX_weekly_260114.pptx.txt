ad-hoc 20% uncertainty on W+HF/LF ratio
post fit 
W+jets
 normalization factor 0.89+/-0.08

not favoured
)
no need to consider W+HF/LF ratio uncertainty
post fit 
W+jets
 normalization factor 1.91+/-0.52 (how to interpret ~2sigma deviation from SM? we know data is likely fluctuated)
5~10% sensitivity loss
Difficult to define the VR. 0tau0b and 1tau0b regions are not useful
both 0tau0b and 0tau1b in the fit, to give a constraint on W+HF/LF ratio uncertainty (
fine to use, but a bit aggressive
)
post fit 
W+jets
 normalization factor 0.91+/-0.08
1sigma post-fit pull observed for W+HF/LF ratio nuisance parameter. Post fit uncertainty on that nuisance parameter is ~0.9 (poor stats in 0tau1b, so not so strong constraint but a bit aggressive comparing to the first method)
no excess observed in all VRs/CRs
Sensitivity is comparable to the first method. 
WVR1tau could be used for the 0b->1b extrapolation validation?

### PAGE 33
Discussion on interference
Confirmed its impact on the final sensitivity is very small.
Now we normalize BSM component by mu and interference by sqrt(mu), which will limit the mu value range to >0. It’s not a problem if we only estimate the upper limit, but we can simply use mu if we can ignore the interference part
But both options (to include, or ignore the interference term) are fine for us. Maybe include it?
